# 브랜드 가이드 (운동친구)

이 문서는 "왜 이 색/디자인으로 정했는지"를 남겨서, 나중에 또 그럴듯한 이유로 색이
바뀌는 걸 방지하기 위한 문서입니다. 색을 바꾸고 싶어지면, 먼저 아래 3원칙 중 뭘 더
잘 만족하는지부터 따져보고 결정하세요.

## 브랜드 3원칙

이 서비스가 표현해야 하는 가치 3가지 (우선순위 아님, 셋 다 동등):

1. **신뢰** — 공공데이터 기반 서비스라는 신뢰감
2. **활력** — 운동·건강을 다루는 서비스다운 생동감
3. **포용성** — 고령층·장애인 접근성을 실제로 고려한 서비스

## 색상 결정 이력

| 시기 | 색상 | 문제점 |
|---|---|---|
| 1차 | 초록 단독 | 활력은 있지만 "신뢰감"이 약함 |
| 2차 | 흑백 단독 (백호돌이 마스코트 컨셉) | 신뢰감은 있지만 "활력" 없음, 차가운 인상 |
| **3차 (현재)** | **흑백 기본 + 주황 포인트 1개** | 3원칙을 모두 만족 |

## 현재 색상 토큰과 용도

`app/globals.css`의 CSS 변수 기준:

- `--primary` (검정): 버튼, 선택된 항목 테두리, 활성 탭 — **구조와 신뢰**를 담당
- `--accent` (주황 `#e8873a`): eyebrow 캡션, 별점, 강조 배지 배경 — **활력**을 담당. 반드시 "포인트"로만 쓰고, 넓은 배경이나 버튼 전체에는 쓰지 않음
- `--bg` / `--card` / `--ink` / `--muted` / `--line` (회색조): 가독성 담당

## 왜 주황인가

- 1988 서울올림픽 마스코트 **호돌이**(오렌지/금색 호랑이)에서 착안. 참고로 우리 데이터
  출처인 "서울올림픽기념국민체육진흥공단"은 1988 서울올림픽 기금으로 설립된 기관이라,
  호돌이는 우리 데이터 출처와 실제로 연결되는 레퍼런스임
- 2018 평창올림픽 마스코트 **수호랑**(백호)에서 로고 컨셉(흑백 라인아트) 착안
- 즉 우리 브랜드는 "수호랑(백호) 실루엣 + 호돌이(주황) 활력"을 결합한 것

## 지켜야 할 규칙 (다음에 색 바꾸고 싶어질 때 체크)

- [ ] 주황(`--accent`)은 절대 넓은 배경색이나 기본 버튼 색으로 쓰지 않는다 (포인트 원칙 유지)
- [ ] 고대비 모드(`body.high-contrast`)는 주황을 쓰지 않고 순수 흑백만 사용한다 (접근성 우선,
      의도적인 예외)
- [ ] 로고(백호 얼굴 SVG)와 헤더 상단 줄무늬는 항상 흑백 유지 (마스코트 정체성)
- [ ] 색을 다시 바꾸고 싶다면, "3원칙 중 뭘 더 잘 만족하는가"를 먼저 답한 뒤 결정한다
